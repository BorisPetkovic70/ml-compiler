\section{Adding ReLu operator}
% -----------------------------
As before, extend \path{hc_dialect.py} with HCRelu.
Note: This time we only have one operand. 
Register operation.
Here is one helper funtion that we will use:
\begin{lstlisting} [language=Python, caption={Const conversion helper}]
def _const_i32(value: int) -> arith.ConstantOp:
    return arith.ConstantOp.from_int_and_width(value, 32)
\end{lstlisting}

Change \path{match_and_rewrite} function from the main file:
\begin{lstlisting} [language=Python, caption={Add logic for HCRelu lowering}]
def match_and_rewrite(self, op: Operation, rewriter: PatternRewriter):
    ...
    # ---------------- hc.relu ----------------
    if op.name == "hc.relu":
        x = op.operands[0]
        c0 = _const_i32(0)

        if hasattr(arith, "MaxSIOp"):
            maxop = arith.MaxSIOp(x, c0.result)
            rewriter.replace_op(
                op,
                new_ops=[c0, maxop],
                new_results=[maxop.result],
                safe_erase=True,
            )
            return
        else:
            raise RuntimeError(
                "Cannot lower hc.relu: arith.MaxSIOp needed."
            )

\end{lstlisting}
Change \path{build_module} function to include HCRelu operation and run the script.
If \path{arith.maxsi(x , 0)} is available, you should see \path{hc.relu}
lowered to 2 operations: \path{arith.constant} and \path{arith.maxsi}.
